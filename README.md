# Gym App 🏋️

A gym app to create workouts and log your weights, sets and reps.

🚧 **Status:** work in progress

## Planned features
- [ ] Create workouts
- [ ] Log weights, sets and reps
- [ ] Save workouts
- [ ] See your workout history
- [ ] User accounts

## Technologies

### Phase 1: Frontend
- Angular
- TypeScript
- localStorage

### Phase 2: Backend
- PHP (REST API)
- MySQL

## Roadmap
1. **Phase 1:** working frontend app with Angular, data saved in localStorage
2. **Phase 2:** PHP + MySQL backend with user accounts and data saved in a database
